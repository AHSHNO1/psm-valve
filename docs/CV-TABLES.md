# راهنمای جدول Cv محصولات

این قابلیت به سایزینگ اجازه می‌دهد به‌جای «جدول Cv عمومی»، از **Cv واقعی هر سری محصول PSM** استفاده کند و سایز پیشنهادی را با نام و شمارهٔ سری درست نشان دهد.

---

## ۱. از کجا وارد کنم؟

پنل مدیریت → گروه **مهندسی** → **جدول Cv سایزینگ**
مسیر: `/admin/cv-tables`

برای هر سری یک کارت هست. کارت را باز کنید، سایزها را وارد کنید و «ذخیره» بزنید. تغییر بلافاصله در صفحهٔ سایزینگ اعمال می‌شود (بدون بیلد).

## ۲. چه عددی وارد کنم؟

- **Cv کاتالوگی در ۱۰۰٪ بازشدگی** و برای **ترم خطی (Linear)**.
- Cv بدون واحد است؛ همان عددی که کاتالوگ سازنده می‌دهد (تعریف: gpm آب در ۶۰°F با ۱ psi افت).
- اگر ترم Equal% دارید، Cv نامی همان سایز را وارد کنید (مقدار ۱۰۰٪).
- اگر فقط بخشی از سایزها را دارید، همان‌ها را وارد کنید؛ بقیه لازم نیست.

## ۳. قالب ورود

دو راه:

1. **ردیف‌به‌ردیف:** «+ افزودن سایز» → `DN50` و `45`
2. **چسباندن گروهی:** کادر «چسباندن چند سایز» را باز کنید و در هر خط:

```
DN50, 45
DN80, 90
DN100, 150
```

جداکنندهٔ `,` یا `;` یا `=` یا فاصله قابل قبول است. قالب `DN` الزامی است.

## ۴. سایزینگ چطور انتخاب می‌کند؟

1. Cv محاسبه‌شده (با احتساب `Fp` در صورت وارد کردن DN لوله) گرفته می‌شود.
2. **حاشیهٔ طراحی:** Cv هدف = `Cv محاسبه‌شده ÷ 0.8` تا شیر در حداکثر دبی حدود ۸۰٪ باز باشد.
3. در بین سری‌های دارای جدول، ابتدا خانواده‌های کنترلی (گلوب/روتاری/دما بالا) بررسی می‌شوند.
4. کوچک‌ترین Cv که از هدف بزرگ‌تر یا مساوی است انتخاب می‌شود.
5. اگر هیچ سایزی به هدف نرسد، نزدیک‌ترین Cv بالاتر از نیاز انتخاب می‌شود و بازشدگی بالای ۸۰٪ در نتیجه دیده می‌شود.
6. اگر هیچ جدولی برای آن نیاز موجود نباشد، سایزینگ به **جدول عمومی** برمی‌گردد و برچسب «Cv عمومی» را نشان می‌دهد.

## ۵. ساختار فایل داده

`data/valve-cv-tables.json`

```json
{
  "schemaVersion": 1,
  "updatedAt": "2026-10-17T20:01:36.811Z",
  "series": {
    "51000": {
      "sizes": [
        { "dn": "DN50", "cv": 45 },
        { "dn": "DN80", "cv": 90 }
      ],
      "updatedAt": "2026-10-17T20:01:36.811Z"
    }
  }
}
```

- کلید `series` همان شمارهٔ سری محصول است (مثل `51000`).
- `dn` باید `DN` + عدد باشد؛ `cv` عددی مثبت.
- نوشتن **اتمیک** است (فایل موقت + rename) و **فقط سری جاری** بازنویسی می‌شود؛ دو تب هم‌زمان دادهٔ هم را پاک نمی‌کنند.

## ۶. API

| متد | مسیر | دسترسی | بدنه |
|---|---|---|---|
| GET | `/api/cv-tables` | ادمین | — |
| PUT | `/api/cv-tables` | ادمین | `{ "series": "51000", "sizes": [{"dn":"DN50","cv":45}] }` |
| DELETE | `/api/cv-tables?series=51000` | ادمین | — |

خطاهای اعتبارسنجی با `400` و آرایهٔ `errors` برمی‌گردند. بدون نشست معتبر `401` است.

## ۷. عیب‌یابی

| نشانه | علت | راه‌حل |
|---|---|---|
| برچسب «Cv عمومی» | سری جدول ندارد یا Cv آن کمتر از نیاز است | جدول همان سری را تکمیل کنید |
| خطای «قطر باید مثل DN50 باشد» | قالب DN رعایت نشده | `DN50` بنویسید، نه `2 inch` |
| بازشدگی بالای ۸۰٪ | بالاترین سایز ثبت‌شده کافی نیست | سایز بزرگ‌تر را وارد کنید یا شیر بزرگ‌تر انتخاب شود |
| تغییرات دیده نمی‌شود | صفحهٔ سایزینگ را رفرش کنید | داده در همان درخواست بعدی خوانده می‌شود |

## ۸. نکتهٔ مهندسی

این جدول فقط **Cv** را نگه می‌دارد. برای انتخاب نهایی، محدودهٔ فشار/دما، متریال بدنه و ترم، کلاس نشتی (FCI 70-2) و شرایط کاویتاسیون هم باید بررسی شود. خروجی ابزار «پیشنهاد» است، نه تأییدیهٔ خرید.
