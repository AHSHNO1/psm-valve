پورت اپ پیشفرض ۳۰۰۰ است. با --port <number> یا متغیر APP_PORT عوض میشود و در
فایل .app-port (ریشهٔ پروژه روی سرور) ذخیره میشود؛ Nginx، PM2 و بررسیهای
سلامت همه از همان یک فایل میخوانند. مسیر Docker پورت ثابت 3000:3000 دارد و
فایل .app-port را نمیخواند.

-------------------------------------------------------------------------------
۰) انتخاب مسیر انتشار
-------------------------------------------------------------------------------
  ۱) VPS تازه (توصیهشده) : sudo bash deploy/install.sh --domain <domain> --email <email>
  ۲) همان کار از ویندوز   : .\deploy\install-remote.ps1 -Server <IP> -Domain <domain>
  ۳) Docker               : bash deploy/docker.sh
  ۴) هاست اشتراکی cPanel  : راهنمای deploy/cpanel/README.md (Node.js Selector)
  ۵) نصب موجود (آپدیت)    : su - psm -c 'bash /var/www/psm-valve/deploy/update.sh'

-------------------------------------------------------------------------------
۱) پیشنیازها
-------------------------------------------------------------------------------
  * سرور Ubuntu 22.04/24.04 یا Debian 12 با دسترسی root یا sudo
  * دامنه: رکورد A برای دامنه و www به IP سرور — قبل از نصب، برای صدور SSL
  * پورتهای ۸۰ و ۴۴۳ باز (ufw را خود اسکریپت تنظیم میکند)
  * دسترسی سرور به GitHub برای git clone؛ در نصب اول لازم نیست کد را کپی کنی
  * رم ۱GB به بالا (روی سرورهای کمحافظه، اسکریپت ۲GB سواپ میسازد)

-------------------------------------------------------------------------------
۲) نصب یکدستوری (۱۱ گام)
-------------------------------------------------------------------------------
داخل سرور:

  sudo bash deploy/install.sh --domain psmvalve.com --email admin@psmvalve.com

با پورت غیرپیشفرض:

  sudo bash deploy/install.sh --domain psmvalve.com --email admin@psmvalve.com --port 8080

با install-remote.ps1 از ویندوز (اسکریپت را با scp میفرستد، با ssh اجرا میکند و
در پایان دادهها را با push-assets.ps1 منتقل میکند):

  .\deploy\install-remote.ps1 -Server 1.2.3.4 -Domain psmvalve.com -Email admin@psmvalve.com
  .\deploy\install-remote.ps1 -Server 1.2.3.4 -Domain psmvalve.com -Port 8080
  .\deploy\install-remote.ps1 -Server 1.2.3.4 -Domain psmvalve.com -SkipBuild -SkipAssets

گزینههای install.sh:
  --domain <domain>         اجباری؛ پیشوند www خودکار مدیریت میشود
  --email <email>           ایمیل Let's Encrypt (پیشفرض admin@<domain>)
  --repo <git-url>          پیشفرض: https://github.com/AHSHNO1/psm-valve.git
  --branch <name>           پیشفرض: main
  --app-dir <path>          پیشفرض: /var/www/psm-valve
  --app-user <user>         پیشفرض: psm
  --port <number>           پیشفرض: 3000 — در .app-port ذخیره میشود
  --admin-user <user>       پیشفرض: admin
  --admin-password <pass>   اگر ندهید رمز تصادفی ساخته و یکبار نمایش داده میشود
  --no-ssl                  فقط HTTP (وقتی DNS/SSL آماده نیست)
  --no-firewall             بدون ufw و fail2ban
  --no-cron                 بدون cron بکاپ روزانه
  --skip-build              پرش از بیلد (اگر .next از قبل آماده است)
  -h, --help                راهنما
  (هر گزینه دو شکل --flag value و --flag=value را میپذیرد. اجرای دوبارهٔ اسکریپت
   بیخطر است و دادهٔ موجود یعنی data/ و public/uploads را پاک نمیکند.)

گامهایی که اجرا میشود:
  ۱) بررسی سیستمعامل و پیشنیازها
  ۲) نصب بستههای پایه + Node.js 20 LTS + PM2 (+ Certbot)
  ۳) ساخت کاربر psm، پوشههای پروژه/بکاپ و سواپ ۲GB
  ۴) git clone در نصب اول یا git pull در اجرای دوباره
  ۵) npm ci
  ۶) ساخت .env.production با اسرار تصادفی (دسترسی 600)
  ۷) تنظیم رمز پنل بهصورت هش bcrypt در data/admin.json
  ۸) npm run build (بعد از ساخت env، چون JWT_SECRET در زمان بیلد درونریزی میشود)
  ۹) اجرای دائمی با PM2 + pm2 save + pm2 startup
 ۱۰) Nginx + SSL رایگان + ریدایرکت http→https و بدون-www→www + ufw و fail2ban
 ۱۱) cron بکاپ روزانه (۳ بامداد) + بررسی سلامت + چاپ خلاصه/رمز پنل

-------------------------------------------------------------------------------
۳) پایان نصب — چه چیزی تحویل میگیری
-------------------------------------------------------------------------------
  سایت      : https://www.<domain>/fa
  پنل       : https://www.<domain>/admin
  رمز پنل   : در خلاصهٔ خروجی اسکریپت + فایل /root/psm-initial-admin-password.txt
  مسیر پروژه: /var/www/psm-valve  (کاربر اجراکننده: psm)
  لاگها     : /var/www/psm-valve/logs/pm2-out.log و pm2-error.log · logs/backup.log
  بکاپها    : /var/backups/psm-valve
  کانفیگ وب : /etc/nginx/sites-available/psmvalve.conf
  پورت      : /var/www/psm-valve/.app-port

  ⚠️ بعد از اولین ورود، رمز پنل را عوض کن (چکلیست بخش ۱۲).
  ⚠️ اگر SSL صادر نشد (DNS هنوز آماده نبود) بعد از ست شدن DNS:

       certbot certonly --webroot -w /var/www/html -d www.<domain> -d <domain>
       bash /var/www/psm-valve/deploy/install.sh --domain <domain> --skip-build

     (یا از ابتدا با --no-ssl نصب کن و بعد از DNS دوباره بدون آن اجرا کن.)

-------------------------------------------------------------------------------
۴) بررسی سلامت بعد از نصب یا آپدیت
-------------------------------------------------------------------------------
  su - psm -c 'pm2 status'
  su - psm -c 'pm2 logs psm-valve --lines 50'
  curl -I "http://127.0.0.1:$(cat /var/www/psm-valve/.app-port)/fa"      # باید 200
  curl -I "http://127.0.0.1:$(cat /var/www/psm-valve/.app-port)/admin"   # باید 307
  curl -I "http://127.0.0.1:$(cat /var/www/psm-valve/.app-port)/api/cv-tables"  # باید 401
  curl -I "https://www.<domain>/fa"                                      # باید 200
  curl -I "https://www.<domain>/admin"                                   # باید 307 به /admin/login

  نمایش پورت فعال: cat /var/www/psm-valve/.app-port

-------------------------------------------------------------------------------
۵) تغییر پورت روی نصب موجود
-------------------------------------------------------------------------------
راه ۱ — توصیهشده (خودِ اسکریپت .app-port و Nginx را هماهنگ میکند):

  sudo bash /var/www/psm-valve/deploy/install.sh --domain <domain> --port 8080 --skip-build

راه ۲ — دستی:

  cd /var/www/psm-valve
  echo 8080 | sudo tee .app-port
  sudo chown psm:psm .app-port
  sudo sed -E -i 's/127\.0\.0\.1:[0-9]+/127.0.0.1:8080/g' /etc/nginx/sites-available/psmvalve.conf
  sudo nginx -t && sudo systemctl reload nginx
  su - psm -c "cd /var/www/psm-valve && pm2 reload ecosystem.config.js --update-env && pm2 save"

  ⚠️ مهم: pm2 reload با نام اپ (مثلاً pm2 reload psm-valve) فایل ecosystem.config.js
     را دوباره نمیخواند، پس پورت جدید اعمال نمیشود. همیشه ecosystem.config.js را بده.
  • APP_PORT=8080 bash deploy/update.sh فقط برای همان اجرا پورت/دامنه را بازنویسی میکند.
  • نکتهٔ دامنه: install.sh دامنه را از --domain میگیرد و کاری با data/settings.json
    ندارد؛ مقدار دامنه در settings.json فقط برای sitemap/canonical و لینکهای تماس است.

-------------------------------------------------------------------------------
۷) انتشار نسخهٔ جدید (آپدیت) و چرخاندن رمز
-------------------------------------------------------------------------------
  su - psm -c 'bash /var/www/psm-valve/deploy/update.sh'

چهار گام update.sh:
  ۱) پیشبررسی: node scripts/preflight.mjs  (اگر FAIL بدهد متوقف میشود)
  ۲) انتشار: بکاپ دادهٔ زنده → دریافت کد → npm ci → npm run build →
     pm2 reload ecosystem.config.js --update-env   (دادهٔ سرور حفظ میشود)
  ۳) تستهای رگرسیون: npm test
  ۴) بررسی سلامت: /fa (۲۰۰) · /admin (۳۰۷) · /api/cv-tables (۴۰۱) و دامنه (اگر DOMAIN بدهی)

  متغیرهای update.sh: APP_DIR · BRANCH · APP_NAME · APP_PORT · DOMAIN
  مثال: DOMAIN=psmvalve.com bash deploy/update.sh

  چرخاندن رمز پنل (اولین نصب یا بعد از افشا):

    su - psm -c 'cd /var/www/psm-valve && node scripts/rotate-admin-password.mjs'

  آپدیت Docker : git pull  &&  docker compose up -d --build
  آپدیت cPanel : git pull  &&  npm ci  &&  npm run build  → Restart در پنل

-------------------------------------------------------------------------------
۸) بکاپ و بازگردانی
-------------------------------------------------------------------------------
  بکاپ دستی : su - psm -c 'bash /var/www/psm-valve/deploy/backup.sh'
  زمانبندی : cron روزانه ساعت ۳ بامداد (install.sh نصب میکند)
  لاگ      : >> /var/www/psm-valve/logs/backup.log 2>&1
  نگهداری  : ۱۴ روز (KEEP_DAYS)   ·   مسیر: /var/backups/psm-valve
  متغیرها   : APP_DIR · BACKUP_DIR · KEEP_DAYS

  محتوای هر بکاپ:
    data-<stamp>.tar.gz              همهٔ data/*.json (محتوا، تنظیمات، پیامها، مقالات)
    products-<stamp>.sqlite          اسنپشات تراکنشی کاتالوگ محصولات
    uploads-<stamp>.tar.gz           داراییهای public/uploads
    products-seed-<stamp>.js         فقط اگر SQLite هنوز ساخته نشده باشد
    ecosystem.config.js-<stamp>      کانفیگ PM2
    app-port-<stamp>                 پورت فعال اپ
    env-production-<stamp>           نسخهٔ .env.production (دسترسی 600)

  بازگردانی دادهٔ JSON :

    tar -xzf /var/backups/psm-valve/data-<stamp>.tar.gz -C /var/www/psm-valve
    su - psm -c "cd /var/www/psm-valve && pm2 reload psm-valve"

  بازگردانی کاتالوگ SQLite :

    cp /var/backups/psm-valve/products-<stamp>.sqlite /var/www/psm-valve/data/psm-valve.sqlite

  بازگردانی تصاویر و آپلودها :

    tar -xzf /var/backups/psm-valve/uploads-<stamp>.tar.gz -C /var/www/psm-valve

  بازگردانی کانفیگ: cp backup/app-port-<stamp> → .app-port و سپس
    pm2 reload ecosystem.config.js --update-env

  مسیر Docker: bash deploy/backup-docker.sh
  ⚠️ بکاپ خارج از سرور (در خودِ اسکریپت هم پیشنهاد شده):
    rsync -az --delete "$BACKUP_DIR/" backupuser@<host>:/backups/psm-valve/
    rclone copy /var/backups/psm-valve remote:psm-valve-backups

۹) مسیر Docker
-------------------------------------------------------------------------------
  bash deploy/docker.sh                            # env + بیلد + بالا آوردن + رمز مدیر
  bash deploy/docker.sh --admin-password '<رمز>'   # با رمز دلخواه
  bash deploy/docker.sh -h                         # راهنما
  (متغیرهای محیطی جایگزین: ADMIN_USERNAME · ADMIN_PASSWORD · PORT)

  docker compose logs -f app        # لاگ زنده
  docker compose restart app        # ریاستارت
  docker compose up -d --build      # بیلد مجدد و بالا آوردن
  docker compose down               # توقف (داده باقی میماند)
  bash deploy/backup-docker.sh      # بکاپ دادهٔ کانتینری

  دادهٔ مانا: ./data (JSON + SQLite) · ./public/uploads · volume psm-next (خروجی بیلد)
  پورت: ثابت 3000:3000 — فایل .app-port در Docker اصلاً خوانده نمیشود. پشت Nginx
        بهتر است در docker-compose.yml پورت را به "127.0.0.1:3000:3000" محدود کنی،
        چون Docker از فایروال ufw رد میشود و خودش پورت را باز میکند.
  ⚠️ تعداد replica همیشه ۱ بماند (محدودسازی نرخ در حافظهٔ همان پروسه و دادهٔ فایلمحور).

۱۱) عیبیابی سریع
-------------------------------------------------------------------------------
  502 Bad Gateway
    su - psm -c 'pm2 status'  &&  su - psm -c 'pm2 logs psm-valve --lines 50'
    ss -tlnp | grep "$(cat /var/www/psm-valve/.app-port)"     # اپ روی پورت listen است؟
    sudo nginx -t  &&  sudo systemctl reload nginx

  «ورود در سرور پیکربندی نشده» یا خطای ۵۰۰ در ورود
    JWT_SECRET یا رمز مدیر تنظیم نشده → .env.production را کامل کن، سپس:
    su - psm -c "cd /var/www/psm-valve && pm2 reload ecosystem.config.js --update-env && pm2 save"

  رمز درست پنل پذیرفته نمیشود
    ADMIN_PASSWORD کمتر از ۱۲ کاراکتر یا هش bcrypt نامعتبر → رمز را بچرخان.

  سایت بالا نیست ولی PM2 سالم است
    /etc/nginx/sites-available/psmvalve.conf را چک کن (proxy_pass به 127.0.0.1:<port>).

  SSL صادر نشد / mixed content
    certbot certonly --webroot -w /var/www/html -d www.<domain> -d <domain>
    sudo systemctl reload nginx

  بیلد روی سرور کمحافظه (OOM)
    free -h  ·  swapon --show      # سواپ ۲GB که install.sh ساخته را چک کن
